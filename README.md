
# LMS Platform

LMS Platform — учебный проект платформы онлайн-обучения, разработанный в рамках обучения на курсе «Python-разработчик» образовательной платформы Skypro.

Проект выполнен в рамках домашней работы 30.1, посвящённой изучению Django REST Framework.

Приложение представляет собой REST API для управления курсами, уроками и профилями пользователей.

## Технологии

- Python 3.12
- Django 5.2
- Django REST Framework (DRF)
- PostgreSQL
- Poetry
- Pillow
- python-dotenv
- Postman
- Git

## Функциональность

### Пользователи

- Собственная модель пользователя на основе AbstractBaseUser.
- Использование email вместо username для авторизации.
- Хранение имени, фамилии, телефона, города и аватара пользователя.
- Просмотр и редактирование профиля пользователя.
- Управление пользователями через административную панель Django.

### Курсы

- Создание курсов.
- Получение списка курсов.
- Получение информации об отдельном курсе.
- Полное и частичное обновление курсов.
- Удаление курсов.
- Загрузка изображений для превью.
- Реализация CRUD через ModelViewSet.

### Уроки

- Создание уроков.
- Получение списка уроков.
- Получение информации об отдельном уроке.
- Полное и частичное обновление уроков.
- Удаление уроков.
- Загрузка изображений для превью.
- Добавление ссылок на видеоматериалы.
- Реализация CRUD через Generic-классы.

### Связь моделей

Модели курса и урока связаны через ForeignKey.

Один курс может содержать несколько уроков. Каждый урок принадлежит одному курсу.

При удалении курса связанные с ним уроки также удаляются.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:oxtishina-svg/Module_7.git
cd Module_7
```

Для клонирования по SSH необходимо предварительно настроить SSH-ключ GitHub.

Также можно использовать HTTPS:

```bash
git clone https://github.com/oxtishina-svg/Module_7.git
```

### 2. Установка зависимостей

Для запуска проекта необходимо установить:

- Python 3.12
- Poetry
- PostgreSQL

Установка зависимостей проекта:

```bash
poetry install --no-root
```

### 3. Настройка базы данных

Создайте базу данных PostgreSQL:

```sql
CREATE DATABASE homework_30_1;
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта на основе файла `.env.example`.

Пример содержимого:

```dotenv
SECRET_KEY=replace-with-your-secret-key
DEBUG=True

DB_NAME=homework_30_1
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

Укажите собственный секретный ключ Django и пароль PostgreSQL.

Файл `.env` содержит конфиденциальные данные и исключён из системы контроля версий.

### 5. Применение миграций

```bash
poetry run python manage.py migrate
```

### 6. Создание администратора

```bash
poetry run python manage.py createsuperuser
```

Для создания администратора используется email вместо имени пользователя.

### 7. Запуск сервера

```bash
poetry run python manage.py runserver
```

После запуска будут доступны:

- REST API: http://127.0.0.1:8000/api/
- Административная панель: http://127.0.0.1:8000/admin/

## Эндпоинты API

### Курсы

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/courses/` | Получение списка курсов |
| POST | `/api/courses/` | Создание курса |
| GET | `/api/courses/{id}/` | Получение информации о курсе |
| PUT | `/api/courses/{id}/` | Полное обновление курса |
| PATCH | `/api/courses/{id}/` | Частичное обновление курса |
| DELETE | `/api/courses/{id}/` | Удаление курса |

### Уроки

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/lessons/` | Получение списка уроков |
| POST | `/api/lessons/create/` | Создание урока |
| GET | `/api/lessons/{id}/` | Получение информации об уроке |
| PUT | `/api/lessons/{id}/update/` | Полное обновление урока |
| PATCH | `/api/lessons/{id}/update/` | Частичное обновление урока |
| DELETE | `/api/lessons/{id}/delete/` | Удаление урока |

### Пользователи

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/users/{id}/` | Получение профиля пользователя |
| PUT | `/api/users/{id}/` | Полное обновление профиля |
| PATCH | `/api/users/{id}/` | Частичное обновление профиля |

## Примеры запросов

### Создание курса

POST `/api/courses/`

```json
{
    "title": "Python Backend",
    "description": "Курс по разработке серверных приложений на Python."
}
```

### Создание урока

POST `/api/lessons/create/`

```json
{
    "title": "Введение в Django REST Framework",
    "description": "Знакомство с REST API и сериализаторами.",
    "video_url": "https://example.com/video/1",
    "course": 1
}
```

Значение поля `course` должно соответствовать ID существующего курса.

### Редактирование профиля пользователя

PATCH `/api/users/1/`

```json
{
    "first_name": "Test",
    "last_name": "User",
    "city": "Saint Petersburg",
    "phone": "+79990000000"
}
```

## Работа с изображениями

Для загрузки изображений используются поля ImageField и библиотека Pillow.

Поддерживается загрузка:

- Превью курсов.
- Превью уроков.
- Аватаров пользователей.

Для отправки изображений через API необходимо использовать формат `multipart/form-data`.

Загруженные файлы сохраняются в директории `media/`, которая исключена из системы контроля версий.

## Тестирование

Для автоматического тестирования используются Django TestCase и DRF APITestCase.

Тесты охватывают:

- Создание обычного пользователя.
- Создание администратора.
- Авторизацию по email.
- Получение и редактирование профиля.
- Ограничение изменения административных полномочий через API.
- CRUD-операции для курсов.
- CRUD-операции для уроков.
- Проверку связи между курсами и уроками.
- Каскадное удаление связанных объектов.
- Валидацию обязательных полей.

Запуск всех автоматических тестов:

```bash
poetry run python manage.py test
```

Для ручного тестирования эндпоинтов используется Postman.

## Проверка качества кода

В проекте используются следующие инструменты разработки:

- Black — автоматическое форматирование кода.
- isort — сортировка импортов.
- Flake8 — статический анализ кода.

```bash
poetry run python -m black users lms config
```

Проверка конфигурации Django:

```bash
poetry run python manage.py check
```

## Особенности реализации

- Используется собственная модель пользователя на основе AbstractBaseUser и PermissionsMixin.
- Email является основным идентификатором пользователя.
- Для сериализации данных используется ModelSerializer.
- CRUD курсов реализован через ModelViewSet.
- CRUD уроков реализован через отдельные Generic-классы.
- Редактирование профиля пользователя реализовано через RetrieveUpdateAPIView.
- Для хранения данных используется PostgreSQL.
- Для управления зависимостями используется Poetry.
- Конфиденциальные параметры хранятся в переменных окружения.
