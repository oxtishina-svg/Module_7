
REST API для платформы онлайн-обучения, разработанный
в рамках курса «Python-разработчик» от Skypro.

## О проекте

Проект представляет собой серверную часть образовательной
платформы для управления пользователями, курсами,
уроками и платежами.

В проекте реализованы домашние задания модуля 7:

- 30.1 — Django REST Framework.
- 30.2 — Сериализаторы и фильтры.

## Технологический стек

- Python 3.12
- Django 5.2
- Django REST Framework
- PostgreSQL
- Django Filter

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:oxtishina-svg/Module_7.git
cd Module_7
```

### 2. Установка зависимостей

```bash
poetry install
```

### 3. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`.

```env
SECRET_KEY=your-secret-key
DEBUG=True

DB_NAME=homework_30_1
DB_USER=postgres
DB_PASSWORD=your-password
DB_HOST=localhost
DB_PORT=5432
```

Предварительно создайте соответствующую базу данных
в PostgreSQL.

### 4. Применение миграций

```bash
poetry run python manage.py migrate
```

### 5. Создание администратора

```bash
poetry run python manage.py createsuperuser
```

### 6. Запуск сервера

```bash
poetry run python manage.py runserver
```

API будет доступен по адресу:

http://127.0.0.1:8000/api/

Административная панель:

http://127.0.0.1:8000/admin/

## Заполнение базы данных

Предусмотрено два способа загрузки демонстрационных данных.

### Кастомная команда

```bash
poetry run python manage.py create_payments
```

Команда создаёт:

- тестового пользователя;
- тестовый курс;
- тестовый урок;
- три платежа.

При повторном последовательном запуске команды
существующие демонстрационные платежи не дублируются.

После выполнения команда выводит идентификаторы
пользователя, курса и урока.

### Загрузка фикстуры

```bash
poetry run python manage.py loaddata users/fixtures/payments.json
```

Фикстура содержит пользователя, курс, урок
и три платежа.

Для демонстрации функциональности достаточно
использовать один из способов заполнения базы.

## API Endpoints

### Курсы

| Метод | Endpoint | Описание |
|---|---|---|
| GET | /api/courses/ | Список курсов |
| POST | /api/courses/ | Создание курса |
| GET | /api/courses/{id}/ | Просмотр курса |
| PUT | /api/courses/{id}/ | Обновление курса |
| PATCH | /api/courses/{id}/ | Частичное обновление |
| DELETE | /api/courses/{id}/ | Удаление курса |

### Уроки

| Метод | Endpoint | Описание |
|---|---|---|
| GET | /api/lessons/ | Список уроков |
| POST | /api/lessons/create/ | Создание урока |
| GET | /api/lessons/{id}/ | Просмотр урока |
| PUT | /api/lessons/{id}/update/ | Обновление урока |
| PATCH | /api/lessons/{id}/update/ | Частичное обновление |
| DELETE | /api/lessons/{id}/delete/ | Удаление урока |

### Пользователи

| Метод | Endpoint | Описание |
|---|---|---|
| GET | /api/users/{id}/ | Просмотр профиля |
| PUT | /api/users/{id}/ | Обновление профиля |
| PATCH | /api/users/{id}/ | Частичное обновление |

### Платежи

| Метод | Endpoint | Описание |
|---|---|---|
| GET | /api/users/payments/ | Список платежей |

## Фильтрация и сортировка платежей

| Параметр | Значение | Описание |
|---|---|---|
| course | ID курса | Фильтрация по курсу |
| lesson | ID урока | Фильтрация по уроку |
| payment_method | cash | Оплата наличными |
| payment_method | transfer | Оплата переводом |
| ordering | payment_date | От старых к новым |
| ordering | -payment_date | От новых к старым |

### Примеры запросов

Получение всех платежей:

```text
GET /api/users/payments/
```

Фильтрация по курсу:

```text
GET /api/users/payments/?course=3
```

Фильтрация по уроку:

```text
GET /api/users/payments/?lesson=2
```

Фильтрация по способу оплаты:

```text
GET /api/users/payments/?payment_method=cash
```

Сортировка по возрастанию даты:

```text
GET /api/users/payments/?ordering=payment_date
```

Сортировка по убыванию даты:

```text
GET /api/users/payments/?ordering=-payment_date
```

Комбинированная фильтрация:

```text
GET /api/users/payments/?lesson=2&payment_method=transfer
```

Идентификаторы объектов зависят от содержимого базы данных.

## Модель платежа

Модель Payment содержит следующие поля:

| Поле | Описание |
|---|---|
| user | Пользователь |
| payment_date | Дата оплаты |
| course | Оплаченный курс |
| lesson | Оплаченный урок |
| amount | Сумма оплаты |
| payment_method | Способ оплаты |

На уровне базы данных реализованы ограничения:

- Платёж относится либо к курсу, либо к уроку.
- Сумма платежа должна быть положительной.
- Оплаченные курсы и уроки защищены от удаления
  при наличии связанных платежей.

## Сериализация данных

Сериализатор курса дополнительно возвращает:

- lessons_count — количество уроков;
- lessons — список уроков с подробной информацией.

Сериализатор пользователя дополнительно возвращает:

- payments — историю платежей;
- вложенную информацию об оплаченных курсах и уроках.
